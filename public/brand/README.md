# Brand assets

`chase-octagon.png` is the supplied Chase mark, used as an asset and never redrawn.

Spec `09 §12` and the source-of-truth warning at the top of `09-chase-brand.md`
both require this: the octagon mark and the "Chase" wordmark are registered
trademarks, so the only permitted use is a supplied file. Nothing in this
repository draws an approximation of either, and nothing should.

Before production, confirm this is the correct asset from the internal Chase
design system rather than a copy of convenience, and confirm the licensed Open
Sans build alongside it.

The word "Chase" set as ordinary text in the rail lockup is text, not a
reproduction of the wordmark lockup. If Brand disagrees, replace the text with a
supplied wordmark asset in [chase-logo.tsx](../../src/components/shell/chase-logo.tsx).
